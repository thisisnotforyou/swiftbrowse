# SwiftBrowse ad-blocking WebView extension

This is a small local fork of [`adblocker_webview` 2.3.0](https://github.com/islamdidarmd/flutter_adblocker_webview), licensed under BSD-3-Clause. It adds a navigation URL predicate and callback so SwiftBrowse can route recognizable file links to its download manager. Upstream library code and the original license are retained.
